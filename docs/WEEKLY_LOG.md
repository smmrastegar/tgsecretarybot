یک بخش برای هر اجرا (جدیدترین بالا). روش اجرا: `docs/WEEKLY_UPGRADE.md`.

## ۲۰۲۶-۱۰-۲۳ (جمعه) — اجرای اول

**وضعیت اولیه (اندازه‌گیری):**
- امتیاز پایداری روز قبل: ۶۰ (۶۱ خطا از ۱۹۱۲ پیام). منابع خطا: classifier ×۱۵۳، bot ×۷۸، rules ×۴۱ (همه ۴۲۹ از OpenRouter)، deploy:spotdl ×۳۵ (خودآزمایی spotDL هر ساعت شکست می‌خورد).
- اسپاتیفای: محدودیت ۲۳ ساعتهٔ ۲۱ اکتبر تمام شده؛ اصلاح نام ساندکلاود کامل شد (۱۴۴ خودکار، ۱۵ دستی، ۳۹ منتظر بررسی دستی). ساندکلاود: ۱۹۸ آهنگ، همه آماده؛ لایک‌های تازه هر ۶ ساعت بررسی می‌شود.
- کتابخانه: ۸۶۱ آهنگ اسپاتیفای + ۱۹۸ ساندکلاود + ۳ دستی؛ ۳ دانلود ناموفق.

**تغییرها:**
- متریک سلامت API (`api_health_daily`، آزمایش ۶ ساعته، کارت داشبورد، بخش «موزیک و APIها» در گزارش شبانه).
- تلاش مجدد مؤدبانهٔ OpenRouter روی ۴۲۹/۵۰۲/۵۰۳ (کاهش خطای تکراری).
- خودآزمایی spotDL: تلاش مجدد حداکثر هر ۶ ساعت (به‌جای هر ساعت) و به‌روزرسانی yt-dlp پیش از آزمون. توجه: بازبینی ۱۲ اکتبر نشان داده بود علت اصلی بلاک‌شدن IP سرور توسط YouTube است؛ اگر باز هم شکست خورد، علت همین است و فقط نویز لاگ کم شده.
- برنامهٔ «ارتقای هفتگی» (همین مستند + مهارت `weekly-upgrade`).

**باز مانده:** ببینید نقشهٔ راه (`source: weekly`).
